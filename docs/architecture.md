# Архитектура FUDE

> Статус: всё на схеме работает — редактор с темой FUDE, ядро уроков, встроенные уроки, приложение на Tauri + SvelteKit с прогрессом в SQLite. Подробности о приложении — в [app.md](app.md).

## Общая схема

```text
┌─────────────────────────────────────────────────────┐   JSON-канал команд    ┌──────────────────────────┐
│  Приложение FUDE (Tauri)                            │  ────────────────────▶ │  Редактор PhotoCraft     │
│                                                     │   ui.set, ui.pointer,  │  (отдельный процесс,     │
│  интерфейс (SvelteKit + TypeScript, webview):       │   engine.execute,      │   egui + wgpu,           │
│  главная, каталог, урок, редактор уроков,           │   app.open / app.save  │   тема FUDE Тушь)        │
│  достижения, активность, статистика                 │  ◀──────────────────── │                          │
│                                                     │   ui.inspect: инстру-  │  --control <порт>        │
│  ядро fude-core (Rust):                             │   мент, кисть, слои,   │  --automation-read-root  │
│  уроки, проверка, пакеты .fude, гайды, подсказки    │   масштаб, история     │  --automation-write-root │
│                                                     │                        │                          │
│  SQLite: прогресс, активность, статистика           │                        │                          │
└─────────────────────────────────────────────────────┘                        └──────────────────────────┘
          │ читает и пишет
          ▼
  папки уроков: встроенные (lessons/, только чтение) и пользовательские (%APPDATA%\ru.fude.app\lessons)
```

Всё работает на компьютере ученика. Учётных записей, сервера и синхронизации нет.

## Почему редактор — отдельный процесс

- PhotoCraft — нативное приложение на egui/wgpu. Его правила ([`photocraft/AGENTS.md`](../photocraft/AGENTS.md)) запрещают оборачивать его в Tauri или webview.
- В PhotoCraft любое действие — команда, и есть JSON-канал управления (`--control <порт>`, протокол — [`photocraft/docs/control-protocol.md`](../photocraft/docs/control-protocol.md)). Через него приложение:
  - открывает файл задания (`app.open`) и сохраняет холст для проверки (`app.save`);
  - выбирает инструменты и параметры (`ui.set`, `tools.setBrush`);
  - проигрывает гайд: штрихи (`paint.stroke`), слои, выделения;
  - читает состояние (`ui.inspect`): активный инструмент, кисть, масштаб, слои, выделение, историю;
  - ставит тему (`ui.set {"theme":"fudeInk"}`).
- Файлы редактор открывает и пишет только внутри двух корней, которые ему выдаёт приложение при запуске: `--automation-read-root` — папка урока, `--automation-write-root` — временная папка попытки. Абсолютные пути и `..` редактор сам отклоняет.
- Окно редактора на Windows встраивается в окно FUDE: FUDE делает главное окно процесса PhotoCraft дочерним окном своего окна без рамки и ставит его над местом, которое отмечает страница; «Отдельное окно» возвращает его. Процесс при этом остаётся отдельным, а через `ui.set {"hostEmbedded": true}` редактор прячет свои кнопки окна. Подробно — [app.md](app.md#редактор-в-окне-fude-или-отдельно).
- Канал слушает только `127.0.0.1` и требует токен. Приложение создаёт файл токена в своей папке данных, передаёт его через `--control-token-file` и первой строкой каждого соединения отправляет `auth`.

## Ядро `fude-core`

Модули ([`core/src/`](../core/src/)):

| Модуль | Что делает |
|---|---|
| `model` | типы `Category`, `Lesson`, `Task`, `Step`, `Check`, `Hint`, `Quiz` и их чтение из TOML |
| `library` | обходит корни уроков, собирает категории и уроки; плохой урок не ломает каталог, а попадает в список ошибок |
| `validate` | проверяет урок: поля, сложность 1–5, пути внутри папки урока, существующие файлы, допустимые расширения, уникальность шагов, зависимости |
| `guide` | читает сценарий гайда и пропускает только разрешённые команды редактора |
| `hint` | превращает теневые фигуры подсказки в команды редактора (слой «FUDE · подсказка», полупрозрачные штрихи) |
| `assess` | проверяет шаг задания по состоянию редактора и по снимку холста |
| `package` | экспорт и импорт пакетов `.fude` (zip) с защитой от zip-slip и ограничениями размера |
| `authoring` | создаёт и сохраняет категории и уроки, транслитерирует названия в имена папок, прикрепляет видео и картинки |

Формат уроков и пакетов — в [lesson-format.md](lesson-format.md).

### Гайды

У урока два вида гайда, можно оба сразу:

- **Анимированный гайд** — сценарий `guide.json`: последовательность команд редактора с подписями и паузами. Приложение проигрывает его в настоящем PhotoCraft, ученик видит, как кисть рисует на холсте. Сценарий может вызывать только команды из белого списка (`guide::ALLOWED_COMMANDS`): рисование, слои, выделение, отмена, параметры кисти. Файлы, сохранение, скрипты и сеть запрещены, поэтому чужой импортированный урок не может навредить.
- **Видео** — файл `mp4` или `webm`, который автор загружает в урок. Webview показывает его встроенным плеером.

### Проверка задания

Шаг задания засчитывается, когда проходят все его проверки. Проверки двух видов:

- по состоянию редактора из `ui.inspect`: инструмент, кисть, масштаб, слои, выделение, история;
- по снимку холста (`app.save` в PNG во временную папку): закрашенная доля области, яркость, «область A темнее B», цвет, похожесть на эталон.

Области задаются в долях холста (`[x, y, ширина, высота]` от 0 до 1), поэтому не зависят от размера документа.

### Подсказки

Подсказка шага — текст, цель в интерфейсе (`tool:Brush`, `panel:Layers`, `menu:edit.undo`), на которую приложение наводит кольцо «начните здесь», и теневые фигуры. Фигуры ядро превращает в команды: новый слой «FUDE · подсказка» с непрозрачностью 35%, штрихи цветом киновари. Когда шаг выполнен, приложение удаляет этот слой. Каждое открытие подсказки записывается в статистику.

## Хранение

SQLite в `%APPDATA%\ru.fude.app\fude.db` ([`db.rs`](../app/src-tauri/src/db.rs)):

- `profile` — имя и цель дня;
- `attempt` — урок, начало, конец, итог, подсказки, время, опыт, сходство с эталоном;
- `step` — какой шаг пройден и с подсказкой ли;
- `journal` — события для главной и журнала активности;
- `achievement` — когда получено достижение;
- `stage` — на каком этапе урока остановился ученик.

Активность по дням, серии, навыки и достижения не хранятся отдельно, а считаются из попыток ([`progress.rs`](../app/src-tauri/src/progress.rs)), поэтому не могут разойтись с ними.

## Решения

- Только локальное хранение, без учётных записей.
- Интерфейс — SvelteKit + TypeScript внутри Tauri.
- Уроки — папки с `lesson.toml`; переносятся пакетами `.fude`.
- Пользователь может создавать свои категории и уроки во встроенном редакторе уроков и импортировать чужие из файла.
- Гайд — сценарий команд PhotoCraft и/или загруженное видео.

# Дизайн-система FUDE

Источник правды — макет в Figma: [FUDE 筆 — школа цифрового рисунка](https://www.figma.com/design/dHDrUBG4xsJ8LL2saJHFxs) (страница «01 · Дизайн-система»). Цвета заведены там как переменные коллекции **FUDE / Цвет**, текст — как стили, тени — как стили эффектов. Этот документ повторяет их в текстовом виде и объясняет правила.

## Идея

Японская живопись тушью (суми-э). Тёплая бумага васи вместо белого, чёрная тушь для структуры, мазки кисти, круги энсо и красные печати-ханко как живые акценты. Интерфейс вокруг них остаётся тихим. Цвета пользователь задал сам: голубоватый, красный, оранжевый, белый, чёрный.

### Правила цвета

- **Киноварь — только для главного действия и печатей.** Одна красная кнопка на экране.
- **Индиго — прогресс, рост, выполненные шаги, подсказки.**
- **Хурма — внимание и серии.** Ошибки в задании отмечаются охрой, а не красным: это «почти получилось», а не тревога.
- **Цвет не единственный носитель смысла.** У сложности всегда есть подпись («Лёгкий», «Мастер»), у статуса — иконка.
- Текст всегда проходит WCAG AA: 4,5:1 для обычного, 3:1 для крупного.

## Тушь и формы

- **Мазок кисти** — генерируется программно: центральная линия, ширина, сужающаяся к концу, «сухой» хвост из отдельных волосков и брызги. Используется как подложка активного пункта меню, полосы прогресса, столбцы недельной активности.
- **Энсо** — круг одним мазком, символ завершённости. Заставка, фон боковой панели, рамки наград.
- **Печать-ханко** — красный квадрат с иероглифом: логотип 筆, отметка «пройден» 済, итог урока 完 (пройден) и 再 («ещё раз», тушевая).
- **Горы** — слои размытой туши в индиго для героев экранов и заставки.

## Компоненты (страница «01 · Дизайн-система»)

| Компонент | Варианты | Заметки |
|---|---|---|
| Кнопка | Основная, Акцент, Контурная, Тихая, Подсказка | «Акцент» (киноварь) — одна на экран |
| Сложность | Уровень 1–5 | пять мазков тушью + подпись |
| Чип | — | фильтры, высота 32 px |
| Печать/Ханко | свойство «Знак» | иероглиф меняется |
| Тушь/Энсо, Тушь/Мазок, Тушь/Горы | — | векторные мазки |
| Боковая панель | 5 разделов | активный пункт подчёркнут мазком киновари, поиск вверху |
| Карточка урока | свойства Название, Номер, Длительность, Знак | категория — в чипе на обложке |
| Достижение | Получено / Закрыто | печать в золотом энсо, у закрытого — прогресс |
| Переключатель | — | период или режим |
| Подсказка | Шаг, Действие, Пояснение, Клавиша | номер совпадает с шагом задания |
| Пункт задания | Готово / Текущий / Впереди | для панели редактора |
| Прогресс | — | индиго |

Карточки: скругление 16 px, мягкая тень **без рамки** (рамка плюс тень дают эффект «карточки-призрака»). Мелкие элементы — 12 и 8 px, пилюли — 999.

## Движение

Анимация открытия (страница «03 · Анимация открытия», видео — [design/fude-splash.mp4](../design/fude-splash.mp4)), 3,6 с:

| Время, с | Этап | Кривая |
|---|---|---|
| 0,00–0,42 | падает капля туши | ease-in |
| 0,42–1,50 | тушь растекается по бумаге | cubic-bezier(.16, 1, .3, 1) |
| 0,62–1,50 | кисть рисует энсо (обрезка контура 0 → 100%) | cubic-bezier(.65, 0, .35, 1) |
| 1,50–2,10 | проступает 筆 (blur 22 → 0) | ease-out |
| 2,00–2,72 | название FUDE и подзаголовок | ease-out, задержка 180 мс |
| 2,60–3,05 | удар печати 学 с поворотом и отскоком | ease-in → ease-out |
| 3,05–3,60 | переход к главной | spring |

При системной настройке «уменьшить движение» заставка сокращается до 0,6 с. Микро-анимации интерфейса (мазок под пунктом меню, проявление экранов, заполнение тепловой карты, удар печати при награде, «дыхание» подсказки) описаны на той же странице макета.

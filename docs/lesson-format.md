# Формат уроков FUDE

Версия формата: **1**. Читает и проверяет его ядро [`fude-core`](../core/); проверить папку можно командой:

```bash
cargo run -p fude-core --bin fude -- validate lessons
```

## Библиотека

Библиотека — это один или несколько корней с категориями:

- встроенные уроки — папка [`lessons/`](../lessons/), поставляется с приложением, только для чтения;
- свои и импортированные уроки — `%APPDATA%\FUDE\lessons`, их создаёт редактор уроков и импорт.

```text
lessons/
└── light/                      категория (имя папки = id категории)
    ├── category.toml
    └── 03-sphere-shadow/       урок (имя папки любое, обычно NN-slug)
        ├── lesson.toml         описание урока, задание, проверки
        ├── theory.md           теория (Markdown)
        ├── guide.json          анимированный гайд (необязательно)
        ├── media/guide.mp4     видео (необязательно)
        └── assets/             картинки задания, эталон
```

Если в двух корнях есть категория с одним id, их уроки объединяются. Если совпадает id урока, побеждает первый корень (встроенный), а второй урок попадает в список ошибок библиотеки.

## category.toml

```toml
id = "light"                 # a-z, 0-9, «-»; до 48 символов; совпадает с именем папки
title = "Свет и тень"
kanji = "影"                 # необязательно: иероглиф на карточке
description = "Как свет лепит форму: от источника до рефлекса."
order = 2                    # порядок в каталоге
accent = "shu"               # цвет категории: ai | shu | kaki | kin
author = "FUDE"              # необязательно
```

## lesson.toml

```toml
format = 1
id = "light.sphere-shadow"   # <id категории>.<slug>; уникален во всей библиотеке
title = "Падающая тень от сферы"
summary = "Тень на полу: где она начинается, куда ложится и почему темнее у основания."
difficulty = 3               # 1 — первый день … 5 — мастер
minutes = 20                 # примерная длительность
order = 3                    # порядок внутри категории
skills = ["light", "form"]   # стороны навыка для статистики
requires = ["light.core-shadow"]  # необязательно: уроки, которые открывают этот
author = "FUDE"              # необязательно

[theory]
file = "theory.md"

[guide]                      # нужен хотя бы один из script и video
script = "guide.json"
video = "media/guide.mp4"    # mp4 или webm
poster = "media/poster.png"  # необязательно: кадр до запуска видео

[[quiz]]                     # необязательно: вопросы после теории
question = "Где падающая тень темнее всего?"
options = ["У дальнего края", "У точки касания", "Везде одинаково"]
answer = 1                   # индекс правильного варианта, с нуля
explain = "У точки касания свет почти не попадает под предмет."

[task]
brief = "Нарисуйте падающую тень от сферы на полу."
open = "assets/task.png"     # картинка, с которой начинается задание
reference = "assets/reference.png"  # необязательно: эталон для проверки similar

[[task.steps]]
id = "layer"                 # уникален внутри урока
text = "Создайте новый слой для тени."
  [task.steps.hint]
  text = "Кнопка «Новый слой» внизу панели «Слои»."
  target = "panel:Layers"
  [[task.steps.checks]]
  kind = "layers"
  count = { min = 2 }
```

Вместо `open` можно задать чистый холст:

```toml
[task.canvas]
width = 1200
height = 800
background = "#FFFFFF"
```

Ровно одно из `task.open` и `task.canvas` обязательно.

### Стороны навыка

`tools` (инструменты), `line` (линия), `form` (форма), `light` (свет и тень), `color` (цвет), `composition` (композиция).

### Пути

Все пути — относительные, через `/`, внутри папки урока. Абсолютные пути, `..`, `\` и буквы дисков запрещены. Разрешённые расширения: `md`, `json`, `toml`, `txt`, `png`, `jpg`, `jpeg`, `webp`, `mp4`, `webm`.

## Подсказка шага

```toml
[task.steps.hint]
text = "Возьмите мягкую кисть и проведите от точки касания вправо."
target = "tool:Brush"        # куда навести кольцо «начните здесь»

[[task.steps.hint.shapes]]   # теневые фигуры на холсте
kind = "ellipse"             # ellipse | rect | line | path
rect = [0.42, 0.72, 0.36, 0.08]

[[task.steps.hint.shapes]]
kind = "path"
points = [[0.2, 0.5], [0.4, 0.45], [0.6, 0.5]]
```

Цели (`target`): `tool:<Инструмент>` (как в PhotoCraft: `Brush`, `Eraser`, `RectMarquee`, `EllipseMarquee`, `Zoom`, `Hand`, `Move`, `PaintBucket`, …), `panel:<Панель>` (`Layers`, `Color`, `Brushes`, `History`), `menu:<id команды>` (`edit.undo`, `select.deselect`, …), `option:<параметр>` (`brushSize`, `hardness`, `opacity`).

Координаты фигур — доли холста от 0 до 1. Приложение рисует их на отдельном слое «FUDE · подсказка» (непрозрачность 35%, цвет киновари) и удаляет слой, когда шаг пройден.

## Проверки

Каждая проверка — таблица `[[task.steps.checks]]` с полем `kind`. Шаг пройден, когда проходят все его проверки. У любой проверки может быть поле `message` — что показать ученику, если она не прошла; иначе ядро составит сообщение само.

Шаги проходятся по порядку, и пройденный шаг остаётся пройденным (`assess::Progress`): если на шаге 3 ученик сменил инструмент, шаг 1 «Выберите кисть» не «отменяется». Поэтому проверка, которая должна держаться до конца (например, «свет не потемнел»), ставится в тот же шаг, что и работа, которую она охраняет, а не отдельным шагом. Шаг без проверок засчитывается кнопкой «Готово».

Диапазоны записываются как `{ min = …, max = … }`, любую границу можно опустить.

Области (`region`, `than`) — `[x, y, ширина, высота]` в долях холста.

### По состоянию редактора

| kind | Поля | Что проверяет |
|---|---|---|
| `tool` | `tool` | активный инструмент |
| `brush` | `size` (px), `hardness` (0–1), `opacity` (0–1) | параметры кисти |
| `zoom` | `zoom` (1 = 100%) | масштаб активного окна |
| `layers` | `count` | число слоёв в документе (вместе с группами) |
| `layer` | `name` (часть имени, без учёта регистра), `visible`, `opacity`, `type` (`Pixel`, `Group`, `Type`, `Shape`, …) | есть слой, подходящий под все условия |
| `selection` | `present` (по умолчанию `true`), `width`, `height` (доли холста) | есть ли выделение и его размер |
| `history` | `entries`, `can_redo` | число шагов истории; `can_redo = true` — последний шаг был отменён |
| `foreground` | `color` (`#rrggbb`), `tolerance` (по умолчанию 0,1) | основной цвет |

### По снимку холста

Приложение сохраняет холст в PNG (`app.save`) и сравнивает с исходной картинкой задания (или с цветом чистого холста). Прозрачные пиксели кладутся на белое.

| kind | Поля | Что проверяет |
|---|---|---|
| `coverage` | `region`, `changed` (0–1) | какая доля области изменилась (пиксель изменился, если какой-то канал сдвинулся больше чем на 24 из 255) |
| `luminance` | `region`, `value` (0–1) | средняя яркость области |
| `darker` | `region`, `than`, `by` (по умолчанию 0,05) | область темнее другой хотя бы на `by` |
| `color` | `region`, `color`, `tolerance` (по умолчанию 0,12) | средний цвет области близок к заданному |
| `similar` | `reference` (по умолчанию `task.reference`), `score` (0–1) | похожесть на эталон: обе картинки уменьшаются до 64×64 в оттенках серого, оценка = 1 − средняя разница |

## guide.json — анимированный гайд

```json
{
  "format": 1,
  "title": "Падающая тень",
  "open": "assets/task.png",
  "steps": [
    {
      "caption": "Создаём слой для тени",
      "highlight": "panel:Layers",
      "calls": [
        { "method": "engine.execute", "params": { "command": "layer.new.layer", "params": { "name": "Тень" } } }
      ],
      "pause": 900
    },
    {
      "caption": "Мягкая кисть, малая непрозрачность",
      "highlight": "tool:Brush",
      "calls": [
        { "method": "ui.set", "params": { "tool": "Brush" } },
        { "method": "engine.execute", "params": { "command": "tools.setBrush", "params": { "size": 60, "hardness": 0, "opacity": 0.3 } } }
      ]
    }
  ]
}
```

- `open` или `canvas` (как в `task`) — с чего начинается гайд; можно опустить, тогда гайд идёт в текущем документе.
- `caption` — подпись внизу экрана; `highlight` — цель в интерфейсе (те же, что у подсказок); `pause` — пауза после шага в миллисекундах (0–15000, по умолчанию 600).
- Разрешённые методы: `ui.set` (только `tool`, `zoom`, `center`, `rotation`, `fit`, `brushSize`), `ui.pointer` и `engine.execute`.
- Разрешённые команды `engine.execute`: `paint.stroke`, `layer.new.layer`, `layer.setProps`, `layer.select`, `layer.delete`, `select.rect`, `select.all`, `select.deselect`, `select.inverse`, `edit.fill`, `edit.undo`, `edit.redo`, `tools.setBrush`, `tools.setColors`, `tools.defaultColors`, `tools.swapColors`, `file.new`.
- Ограничения: до 400 шагов, до 2000 вызовов, до 5000 точек в одном штрихе.

Всё остальное (открытие и сохранение файлов, скрипты, горячие клавиши, сеть) сценарий вызвать не может: так импортированный чужой урок не навредит компьютеру ученика.

## Пакет .fude

Пакет — zip-архив для обмена уроками.

```text
my-lessons.fude
├── fude-package.toml
└── <id категории>/
    ├── category.toml
    └── <папка урока>/…
```

```toml
# fude-package.toml
format = 1
title = "Мои уроки акварели"
created_by = "FUDE 0.1.0"
categories = ["watercolor"]
```

При импорте ядро:

1. отклоняет пути с `..`, абсолютные, с `\` и буквами дисков (zip-slip), а также ссылки;
2. ограничивает пакет: до 4000 файлов, файл до 1 ГиБ, всё вместе до 4 ГиБ, расширения из списка выше;
3. распаковывает во временную папку и проверяет каждый урок;
4. отказывается, если id урока уже есть в библиотеке (если не выбрана замена);
5. переносит категории в пользовательский корень и возвращает отчёт: что добавлено, что заменено, предупреждения.

Экспорт собирает выбранную категорию или отдельные уроки вместе с `category.toml` их категории.

## CLI `fude`

```bash
cargo run -p fude-core --bin fude -- help
```

| Команда | Что делает |
|---|---|
| `fude validate <корень>...` | проверить папки уроков, вывести каталог и все ошибки |
| `fude pack <папка категории> <файл.fude> [--title T] [--lesson <папка урока>]...` | собрать пакет из категории или отдельных уроков |
| `fude info <файл.fude>` | показать, что в пакете, и проверить его |
| `fude import <файл.fude> <свои уроки> [--builtin <корень>] [--replace]` | импортировать пакет |
| `fude new-category <свои уроки> <название> [--kanji K] [--accent ai\|shu\|kaki\|kin]` | создать категорию |
| `fude new-lesson <папка категории> <название> [--difficulty 1..5]` | создать урок по шаблону |
| `fude guide <папка урока>` | вывести команды гайда построчно в JSON — их можно отправить в канал PhotoCraft |
| `fude assess <папка урока> <inspect.json> [холст.png] [--confirm <шаг>]...` | проверить задание по сохранённому ответу `ui.inspect` и снимку холста |

## Встроенные уроки и их картинки

Картинки заданий, эталоны и сценарии гайдов встроенных уроков рисует генератор [`core/examples/lesson_art.rs`](../core/examples/lesson_art.rs):

```bash
cargo run -p fude-core --example lesson_art -- lessons
```

Геометрия (шар, тень, складки) задана в нём один раз и согласована с областями проверок в `lesson.toml`. Тест `canvas_checks_pass_on_the_reference_and_fail_on_the_untouched_task` следит, чтобы каждая проверка холста проходила на эталоне и не проходила на нетронутом задании.

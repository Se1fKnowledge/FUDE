# Тесты

В репозитории два набора тестов:

- **ядро уроков `fude-core`** ([`core/`](../core/)) и встроенные уроки ([`lessons/`](../lessons/)) — наш собственный код;
- **редактор** в [`photocraft/`](../photocraft/) — тесты PhotoCraft плюс тесты, которые мы добавили или изменили для FUDE.

Пропущенные тесты (`#[ignore]`) пропускает и сам PhotoCraft: это долгие проверки производительности и тесты, которым нужны внешние корпуса файлов.

## Ядро уроков

Из корня репозитория:

```bash
cargo test -p fude-core                       # всё: модули, библиотека, пакеты, редактор уроков, встроенные уроки
cargo test -p fude-core --test lessons        # только встроенные уроки
cargo clippy -p fude-core --all-targets -- -D warnings
cargo run -p fude-core --bin fude -- validate lessons
```

Набор идёт меньше двух секунд после сборки.

| Модуль | Тесты | Что проверяют |
|---|---|---|
| `paths` | 5 | обычные относительные пути проходят; `..`, `./`, абсолютные пути, буквы дисков, `\`, двойной `/`, двоеточие и управляющие символы отклоняются; расширения без учёта регистра |

| `control` | 4 | вызовы `engine.execute`; задание с картинкой открывается через корень чтения; чистый холст создаётся и тонируется |
| `assess` | 18 | ответ `ui.inspect` разбирается; каждая проверка состояния и холста проходит и падает с понятным русским сообщением; прозрачное считается белым; картинка задания другого размера масштабируется; большие области считаются выборкой; пройденный шаг остаётся пройденным, шаги идут по порядку |
| `authoring` | 3 | русские названия транслитерируются в id; повторы нумеруются; шаблон нового урока корректен |

### Интеграционные — `core/tests/`

| Файл | Тесты | Что проверяют |
|---|---|---|
| `library.rs` | 6 | каталог сортируется по порядку; сломанный урок попадает в «проблемы», а не ломает каталог; свои уроки добавляются во встроенные категории, но не могут подменить встроенный урок; зависимости открывают уроки; скрытые папки пропускаются |
| `package.rs` | 12 | экспорт и импорт возвращают уроки с видео и картинками, без `.exe` и мусора; повторный импорт требует замены; встроенные уроки не заменяются; **zip-slip** (`../`, абсолютные пути, `C:`, `\`), ссылки, чужие типы файлов, дубликаты, превышение числа файлов и размера отклоняются целиком, ничего не оставляя на диске |
| `authoring.rs` | 6 | новая категория и урок сразу видны в библиотеке; черновик с ошибками сохраняется, но помечается; теория, гайд, видео и картинки сохраняются в урок без перезаписи; встроенный урок правится как копия; удалять можно только внутри своих уроков |
| `lessons.rs` | 8 | встроенные уроки без ошибок и предупреждений; две категории по шесть уроков, сложность растёт; уроки открываются цепочкой с первого; у каждого есть теория с советом сэнсэя, вопросы, гайд не короче 5 секунд, подсказки и проверки на каждом шаге; все шесть сторон навыка тренируются; **проверки холста проходят на эталоне и не проходят на нетронутом задании**; подсказки рисуются разрешёнными командами; категории собираются в пакеты |

## Редактор

Из папки `photocraft/`:

```bash
# всё, что затрагивает FUDE: темы, настройки, меню, бренд
cargo test -p photocraft-ui-egui --lib theme::
cargo test -p photocraft-ui-egui --lib prefs_ui
cargo test -p photocraft-ui-egui --lib links
cargo test -p photocraft-engine --lib prefs
cargo test -p photocraft-engine --lib shell_commands

# полные наборы
cargo test -p photocraft-engine --lib
cargo test -p photocraft-ui-egui --lib

# перед коммитом
cargo fmt --all
cargo clippy -p photocraft-engine -p photocraft-ui-egui --lib --tests -- -D warnings
```

Полный набор интерфейса идёт около 45 секунд (после сборки), движка — около 15.

## Проверка дизайна

Макет в Figma проверялся по методике impeccable: независимое дизайн-ревью и автоматический замер слоёв (контраст WCAG, текст мельче 12 px, обрезки, наложения, размер кликабельных зон, свечения). После правок контраст и мелкий текст чистые; оставшиеся отметки — намеренные (водяные знаки, бледные знаки закрытых достижений, приглушённый неработающий редактор на экране ошибки).

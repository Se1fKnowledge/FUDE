## Дальше

1. **Установщик**: положить `photocraft.exe` рядом с `fude.exe` (sidecar в `tauri.conf.json`), собрать `npm run tauri build`, проверить на чистой машине.
2. **Кольца «начните здесь» поверх окна редактора**: сейчас цель подсказки показывается текстом (`tool:Brush`); нужны координаты элементов PhotoCraft из `ui.inspect` и прозрачное окно поверх.
3. **Запись гайда**: в мастерской записывать действия автора в редакторе в `guide.json`, а не писать JSON руками.
4. **Испытание дня** из макета.
5. **Первая готовая версия** в `main`.

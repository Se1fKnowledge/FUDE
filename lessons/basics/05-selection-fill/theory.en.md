# Selection and fill

A selection is a stencil. While it exists, the brush, the eraser and the fill only work inside it. The selection border is shown as a moving dashed line — the "marching ants".

## Selection tools

| Tool | Key | What for |
|---|---|---|
| Rectangular marquee | **M** | rectangles, bands, frames |
| Elliptical marquee | **Shift+M** | circles and ovals |
| Lasso | **L** | any freehand shape |
| Magic wand | **W** | an area of one colour in one click |

Modifiers while selecting:

- **Shift** — an even square or circle;
- **Alt** — draw from the centre;
- **Shift before you start** — add to the current selection, **Alt** — subtract.

## Fill

A selection can be filled in three ways:

1. **Edit › Fill** (Shift+F5) — a window to choose the colour.
2. **Alt+Backspace** — fill with the foreground colour, **Ctrl+Backspace** — with the background colour.
3. The **“Paint bucket”** tool (G) — fills the area of similar colour under the click.

## Useful commands

- **Ctrl+A** — select all.
- **Ctrl+D** — deselect.
- **Ctrl+Shift+I** — inverse: select everything except the current selection.

## Selection and a soft brush

An artists' trick: select a shape and paint with a large soft brush. Inside you get a smooth tone, while the edge stays crisp. In the next category this makes it easy to model light on a ball.

## Sensei's advice

Build a composition from large simple shapes first. If the picture holds in three shapes, details will only adorn it.
